# homebrew-tap

Homebrew tap for ProbstenHias tools.

```sh
brew install --cask ProbstenHias/tap/anexia
```

Casks under `Casks/` are generated by [GoReleaser](https://goreleaser.com) when the source project
is released. Do not edit them by hand.

| Cask | Source |
| --- | --- |
| `anexia` | [ProbstenHias/anexia-cli](https://github.com/ProbstenHias/anexia-cli) |
